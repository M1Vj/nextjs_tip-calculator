# Tip Calculator (Next.js + Tailwind CSS)

A beautiful, responsive tip calculator app built with Next.js 15, Tailwind CSS v4, and React. Inspired by the classic Frontend Mentor challenge, this app helps you split bills and calculate tips easily.

![Screenshot](./tip-calculator-app-main/design/desktop-preview.jpg)

## Features
- Split bills and calculate tips per person
- Custom or preset tip percentages
- Responsive, modern UI
- Built with Next.js App Router and Tailwind CSS v4
- Philippine Peso (₱) currency support

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure
- `app/` — Main Next.js app directory
- `app/components/` — React components (TipCalculator, Input, Keypad, Display, etc.)
- `app/globals.css` — Tailwind CSS v4 and custom theme
- `tailwind.config.ts` — Tailwind config (minimal, most theme in CSS)
